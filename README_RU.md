
# SafeClean

Надежный, безопасный и настраиваемый скрипт очистки системы для Linux-серверов.

## Обзор

SafeClean — это комплексный инструмент для очистки системы, разработанный специально для Linux-серверов. Он безопасно удаляет ненужные файлы, очищает системные журналы и освобождает дисковое пространство, сохраняя при этом стабильность и безопасность системы.

## Возможности

- **Комплексная очистка**: Очищает ресурсы Docker, журналы systemd, кэш APT, старые ревизии Snap и временные файлы
- **Безопасная работа**: Выполняет тщательные проверки перед удалением и избегает удаления критически важных файлов
- **Детальный анализ**: Предоставляет оценку освобождаемого пространства перед выполнением каких-либо действий
- **Гибкое планирование**: Поддерживает как таймеры systemd, так и традиционные задания cron
- **Настраиваемость**: Настраиваемые пороговые значения и поведение через параметры командной строки или интерактивное меню
- **Логирование**: Опциональная интеграция с syslog с поддержкой формата JSON
- **Тестовый режим**: Имитирует операции очистки без внесения реальных изменений
- **Самотестирование**: Встроенная функция самотестирования для проверки целостности скрипта

## Установка

### Быстрая установка (одной командой)

```bash
bash <(wget -qO- https://raw.githubusercontent.com/DigneZzZ/safe-clean-up/main/safeclean.sh) --install
```

Или с помощью curl:

```bash
bash <(curl -s https://raw.githubusercontent.com/DigneZzZ/safe-clean-up/main/safeclean.sh) --install
```

### Ручная установка

```bash
# Скачать скрипт
wget https://raw.githubusercontent.com/DigneZzZ/safe-clean-up/main/safeclean.sh

# Сделать его исполняемым
chmod +x safeclean.sh

# Установить системно
sudo ./safeclean.sh --install
```

### Из репозитория

```bash
git clone https://github.com/DigneZzZ/safe-clean-up.git
cd safe-clean-up
chmod +x safeclean.sh
sudo ./safeclean.sh --install
```

## Использование

### Основное использование

```bash
# Показать справку
safeclean --help

# Анализировать систему без очистки (сухой запуск)
safeclean --dry-run

# Очистить с запросом подтверждения
safeclean

# Очистить без подтверждения (требуются права root)
sudo safeclean --force
```

### Расширенные опции

```bash
# Настроить параметры через интерактивное меню
safeclean --config

# Использовать пользовательский файл конфигурации
safeclean --config-path /path/to/config

# Установить определенное время хранения журналов
safeclean --journal-days 7 --journal-size 300

# Сохранять образы Docker при очистке
safeclean --keep-docker-images

# Включить syslog с форматом JSON
safeclean --syslog --json-log

# Тестовый режим (показывает команды без их выполнения)
safeclean --test-mode
```

### Планирование

```bash
# Запланировать с таймером systemd (рекомендуется для современных систем)
sudo safeclean --schedule-systemd daily

# Запланировать с традиционным cron
sudo safeclean --schedule weekly

# Удалить все запланированные задачи
sudo safeclean --unschedule
```

## Конфигурация

SafeClean может быть настроен через параметры командной строки, интерактивное меню или файлы конфигурации.

### Расположение файлов конфигурации по умолчанию

- Общесистемный: `/etc/safeclean/config`
- Пользовательский: `~/.config/safeclean/config`

### Параметры конфигурации

- `JOURNAL_DAYS`: Количество дней хранения журналов systemd (по умолчанию: 10)
- `JOURNAL_SIZE`: Максимальный размер журнала systemd в МБ (по умолчанию: 500)
- `DOCKER_KEEP_IMAGES`: Сохранять ли образы Docker при очистке (по умолчанию: false)
- `TEMP_FILES_AGE`: Возраст в днях временных файлов для удаления (по умолчанию: 1)
- `USE_SYSLOG`: Включить логирование в syslog (по умолчанию: false)
- `USE_JSON_LOG`: Использовать формат JSON для записей syslog (по умолчанию: false)
- `CONFIRM_APT_AUTOREMOVE`: Запрашивать подтверждение перед apt autoremove (по умолчанию: true)

## Функции безопасности

- Проверка прав root для чувствительных операций
- Безопасная обработка временных файлов
- Проверка открытых файлов перед удалением
- Проверка зависимостей перед выполнением
- Комплексная обработка ошибок и логирование

## Требования

- Bash 4.0 или выше
- Основные утилиты: find, du, df, lsof, bc
- Опционально: systemd (для функциональности таймера)
- Опционально: logger (для интеграции с syslog)
