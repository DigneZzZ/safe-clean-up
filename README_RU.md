Надёжный, безопасный и настраиваемый скрипт очистки системы для Linux-серверов.

---

## 📦 Обзор

**SafeClean** — это универсальный инструмент для **безопасной очистки Linux-серверов**. Он удаляет ненужные файлы, очищает системные журналы, кэш, временные файлы и старые пакеты — **без риска нарушить работу системы**.

Скрипт показывает анализ, предупреждает о возможном объёме очистки и даёт вам контроль — всё просто, гибко и безопасно.

---

## 🚀 Возможности

- 🧹 **Комплексная очистка**: Docker, systemd-журналы, APT, Snap, временные файлы
- 🔐 **Безопасная работа**: тщательная проверка и минимизация риска
- 📊 **Детальный анализ** перед выполнением
- 🛠️ **Гибкая настройка**: конфиг-файлы, параметры CLI и интерактивное меню
- 🧪 **Тестовый режим**: симуляция без удаления
- 🔄 **Планировщик**: поддержка systemd-таймеров и cron
- 📝 **Логирование в syslog**, включая JSON-формат
- ✅ **Встроенное самотестирование**

---

## 📚 Как работает

1. **Проводит анализ системы**: оценивает журналы, кэш, snap, docker и временные файлы.
2. **Выводит отчёт** и примерный объём освобождаемого места.
3. **Выполняет очистку** — только после вашего подтверждения или в `--force` режиме.
4. Поддерживает **симуляцию** через `--dry-run` или `--test-mode`.

---

## 🧠 Когда использовать?

- Когда заканчивается место на диске
- При регулярном обслуживании серверов
- Перед созданием резервной копии
- Автоматически по расписанию (раз в неделю/месяц)

## 🖥️ Примеры использования

```bash
safeclean --dry-run                 # Анализ без удаления
sudo safeclean --force             # Очистка без подтверждения
safeclean --config                 # Настроить параметры вручную
safeclean --schedule-systemd weekly  # Запуск каждую неделю
```

---

## 🔧 Настройка

Конфигурация может быть указана:
- Через CLI: `--journal-days 7`
- В интерактивном меню: `safeclean --config`
- В файле:
  - системный: `/etc/safeclean/config`
  - пользовательский: `~/.config/safeclean/config`
  - кастомный: `--config-path /путь/к/файлу`

### Пример параметров:

| Параметр                | Описание                                       | По умолчанию |
|------------------------|------------------------------------------------|--------------|
| `JOURNAL_DAYS`         | Хранить журналы systemd N дней                 | `10`         |
| `JOURNAL_SIZE`         | Максимальный размер логов в MB                 | `500`        |
| `DOCKER_KEEP_IMAGES`   | Сохранять образы Docker                        | `false`      |
| `TEMP_FILES_AGE`       | Удалять временные файлы старше N дней          | `1`          |
| `USE_SYSLOG`           | Логировать в syslog                            | `false`      |
| `USE_JSON_LOG`         | Использовать JSON-формат логов                 | `false`      |
| `CONFIRM_APT_AUTOREMOVE` | Запрашивать подтверждение apt autoremove    | `true`       |

## ⏱️ Планирование

Поддерживаются `systemd` и `cron`:

```bash
sudo safeclean --schedule-systemd daily   # Через systemd-таймер
sudo safeclean --schedule weekly          # Через cron
sudo safeclean --unschedule               # Удалить задачи
```
